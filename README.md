# weealert

> **AI disclosure:** this app was written with AI-assisted coding (Claude by Anthropic). I direct the design, review the code and test it on my own device.

A tiny Android app that makes a different notification sound for each contact, from one source sound, so you can tell who it is without looking at the screen. Pure Java, no libraries, no permissions, tiny APK.

## How it works

In the default *tone patterns* mode, pick a source sound (any audio file Android can play, or one of the built-in sounds) and how many sounds you need. weealert builds that many 1-4 note patterns out of the source: the rhythm and the pitch of each note change from sound to sound. Patterns are picked to be as far apart as possible, because rhythm and melody contour are much easier to learn by ear than tiny pitch shifts.

- The sounds are deterministic. Asking for more later keeps the earlier ones exactly as they were.
- Each sound is named with a random-looking adjective-noun name (`keen-acorn.wav`) that comes from the pattern itself, so a sound keeps its name even when you change other settings.
- Tap a sound in the list to hear it at notification volume. Tap the source name to hear the source note.
- **Export all** writes the WAV files into the folder you choose. Then set each file as a contact's notification tone inside WhatsApp, Telegram, Signal, Contacts and so on. Choosing the `Notifications` folder helps system tone pickers find the files.

Keep it to roughly 5-12 contacts you really need to tell apart by ear. The list shows the closest pair of sounds as a number; higher is easier to tell apart.

## Getting the sounds into other apps

Four ways, use whichever the other app likes:

- **Tone picker:** weealert answers the system tone picker request, so when an app opens its notification tone chooser, weealert is listed in the "Choose an action" list next to the system picker (the same way Zedge shows up). Tap a sound to hear it, press Use, and it is added to the system tones and handed back to the app. Android 10+.
- **File picker:** weealert registers itself as a storage root, so it shows up in the system file picker (look for "weealert" in the sidebar). The sounds are generated when you open them, nothing is stored. Works in any app that lets you choose an audio file.
- **Add to system tones** (Android 10+): adds the sounds to the Notifications tone library, which is what the system tone pickers list. If you change settings and add again, sounds with the same name are overwritten.
- **Export all:** writes WAV files into a folder you choose.

## Built-in sources

All are generated by maths in code, so they cost nothing in APK size: bell, glass, marimba, kalimba, soft sine, beep, water drop and wood tock. (Earlier builds also had a plucked-string and an electric-piano source; both are retired. A saved choice of one of them falls back to the bell, and the ids of the others are unchanged.)

## Contact voices

The second mode, switched with the Mode button. Instead of tone patterns, each contact's name is spoken as a fast mumble, in the style of Animal Crossing, so the sound is a variation of the name itself.

- **How it sounds:** a small formant synthesizer (a buzzy pulse train through three moving resonant filters, plus filtered noise for consonants). No recordings, no text-to-speech engine, no network; the same name always gives the same sound on every phone.
- **How names become sounds:** simple letter-to-sound rules for names spelled the way they sound, split into syllables. Names in other scripts get a stable made-up mumble. Long-press a contact and choose *Say it as...* to spell it the way it sounds (for example `jorj` for George).
- **Voices:** each contact gets its own voice: pitch, vocal tract size, speed and pitch contour. A new contact takes the voice farthest from everyone else's, and existing contacts never change. *New voice* picks a clearly different one. The list shows how far apart the two closest voices are; higher is easier to tell apart.
- **Contacts:** add from the system contact picker (the app receives only the contact you pick and has no contacts permission) or type a name. Names and voices are stored only on the phone. The name is also used as the tone name, so it shows up in system tone lists; use a nickname if you prefer.
- Everything else works the same: tone picker, file picker, Add to system tones, Export, and the max length, level, sample rate and file name settings.

## Settings

Everything is under *Settings* in the app. The defaults reproduce the original sounds exactly.

| Setting | Meaning |
| --- | --- |
| Max length | Hard cap for a whole sound, 300-5000 ms. Longer patterns are left out and the renderer trims as a last resort. |
| Note length | How much of the source each note uses, 50-1500 ms. |
| Gaps | Up to 4 allowed gaps between note onsets, multiples of 50 ms. |
| Fewest / most notes | 1-4 notes per sound. |
| Cut notes | End each note when the next one starts, so long sources do not blur together. |
| Pitch offsets | Up to 6 semitone offsets from -24 to 24. |
| Rhythm weight | How much a rhythm difference counts against one semitone when spreading the sounds. |
| Variation seed | 0 is the standard set, any other number gives a different but equally spread one. |
| Fade-out, quieter per note, peak level, sample rate | Shaping and output of the WAV files. |
| Reverse | Play the source backwards. |
| Prefix, numbering | File names: `prefix` + name, or `01-name` in pick order. |

## Build

GitHub Actions only. `test.yml` (manual) builds a signed test APK that installs next to the real app, `release.yml` (manual) bumps the version, tags and publishes a signed APK. Both need the secrets `KEYSTORE_B64`, `KEYSTORE_PASSWORD` and `KEY_ALIAS`.
